# Gram Legends ⚔️

**English** is the default language; Persian (فارسی) can be chosen in Settings. Bot messages follow each user's Telegram language.

بازی کارتی جمع‌آوری قهرمان با نبرد خودکار، ساخته‌شده برای **Telegram Mini App**.

## امکانات
- ۱۶ کارت قهرمان با نقش، کمیابی و مهارت ویژه · نبرد کارت در برابر کارت: دشمن‌ها هم کارت‌اند و مهارت ویژه دارند
- ۵ دنیا و ۵۰ مرحله، با یک کارت رئیس در پایان هر دنیا
- **آزمایشگاه ترکیب:** بازیکن خودش ۲ یا ۳ قهرمانش را انتخاب و ترکیب می‌کند؛ ۶۸۰ کارت ترکیبی ممکن (۱۲۰ دوتایی اسطوره‌ای + ۵۶۰ سه‌تایی کیهانی) با تیراژ محدود جهانی و شماره سریال
- **آپلود تصاویر ترکیبی از داخل ربات** با دستور `/art` (فقط ادمین، متغیر `ADMIN_IDS`) — راهنما: `docs/FUSION_ART.md` و فهرست شماره‌ها: `docs/fusion-catalog.html`
- **کارت‌های هولو:** ۳٪ کارت‌های صندوق نسخه‌ی درخشان کلکسیونی دارند
- **۱۴ زبان** با تشخیص خودکار زبان تلگرام/گوشی + راهنمای کامل بازی داخل تنظیمات
- **آرنای آنلاین ۱ در برابر ۱ با شرط سکه:** پیدا کردن حریف هم‌شرط یا دعوت دوست با لینک/کد؛ برنده کل جایزه را می‌برد، مساوی = برگشت سکه‌ها

## امنیت اقتصاد بازی
- داخل تلگرام، **سرور** صاحب سکه‌ها و قهرمان‌هاست (`src/economy.js` همان قوانین را روی گوشی و سرور اجرا می‌کند).
- هر برد مرحله را سرور با همان seed و ضربه‌های بازیکن **دوباره شبیه‌سازی** می‌کند و فقط برد واقعی جایزه می‌گیرد.
- نبرد آرنا کامل روی سرور اجرا می‌شود (`server/pvp.js`) و شرط‌ها تا پایان نبرد نزد سرور می‌ماند؛ اگر سرور ری‌استارت شود، شرط‌ها برگردانده می‌شوند.
- ارتقای قهرمان تا سطح ۳۰ · صندوق معمولی و سلطنتی
- جایزه‌ی ورود روزانه (۷ روزه) · ماموریت‌های روزانه · دستاوردها · صندوق استراحت (سکه‌ی آفلاین)
- صدا و موسیقی (ساخته‌شده با WebAudio، بدون فایل صوتی) · تنظیمات
- **تلگرام:** ذخیره‌ی ابری، جدول برترین‌ها، فروشگاه سکه با **Telegram Stars**، دعوت دوستان با جایزه، لرزش گوشی

## ساختار
| مسیر | توضیح |
|---|---|
| `src/` | خود بازی (HTML/CSS/JS) + تصاویر |
| `server/server.js` | ربات تلگرام + API (بدون وابستگی، Node 18+) |
| `server/test.js` | تست کامل سرور (`node server/test.js`) |
| `tools/build.py` | ساخت نسخه‌ی تک‌فایلی آفلاین در `dist/` |
| `tools/sim.js` | شبیه‌ساز تعادل سختی مراحل |
| `tools/e2e.js` | تست مرورگر با دو کاربر تلگرامِ شبیه‌سازی‌شده (شامل دوئل آرنا) |
| `tools/nav-test.js` | تست همه‌ی مسیرهای برگشت/بستن |
| `server/pvp.js` | آرنای آنلاین: صف، اتاق دعوت، نگه‌داری شرط، اجرای زنده‌ی نبرد |

## راه‌اندازی در تلگرام (۱۰ دقیقه)
1. در تلگرام به **@BotFather** پیام بده → `/newbot` → اسم و یوزرنیم ربات را بده → **توکن** را کپی کن.
2. در **render.com** ثبت‌نام کن → New → **Blueprint** → این ریپو را انتخاب کن (فایل `render.yaml` خودکار خوانده می‌شود).
3. دو متغیر را وارد کن:
   - `BOT_TOKEN` = توکن مرحله‌ی ۱
   - `WEBAPP_URL` = آدرسی که Render به سرویس می‌دهد، مثل `https://ton-legends.onrender.com`
4. بعد از Deploy، ربات خودش دکمه‌ی «🎮 بازی» را در منوی چت تنظیم می‌کند. در ربات `/start` بزن.
5. (اختیاری) در BotFather: `/newapp` تا لینک مستقیم `t.me/YourBot/play` بسازی، و `/mybots → Payments` لازم نیست — Stars بدون تنظیم کار می‌کند.

> سرور روی هر جای دیگری هم اجرا می‌شود: `BOT_TOKEN=... WEBAPP_URL=https://... node server/server.js` (باید HTTPS باشد).

## نسخه‌ی آفلاین
`python3 tools/build.py` → فایل `dist/ton-legends.html` بدون سرور و اینترنت هم کار می‌کند (بدون امکانات آنلاین).
با فعال کردن **GitHub Pages** (Settings → Pages → Source: GitHub Actions)، این نسخه خودکار منتشر می‌شود.

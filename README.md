# Gram Legends ⚔️

بازی کارتی جمع‌آوری قهرمان‌های میم‌کوین با نبرد زنده، ساخته‌شده برای **Telegram Mini App**.

- 🎮 ربات بازی: [@GLegends_bot](https://t.me/GLegends_bot)
- 📢 کانال رسمی: [@gramlegends_game](https://t.me/gramlegends_game)

زبان پیش‌فرض انگلیسی است و بازی به **۱۴ زبان** ترجمه شده (زبان تلگرام بازیکن خودکار تشخیص داده می‌شود). پیام‌های ربات هم به زبان هر بازیکن فرستاده می‌شوند.

> Fan-made game · not affiliated with the projects shown.

## امکانات

**نبرد و پیشرفت**
- ۱۶ قهرمان میم‌کوین با نقش، کمیابی و مهارت ویژه؛ سطح ۱ تا ۱۰۰ با ۵ ستاره
- ۲۰ جهان و ۲۰۰ مرحله؛ هر جهان یک باس با نقطه‌ضعف دارد
- نبرد زنده: کومبوها، ردیف جلو/عقب، ضربه‌ی نهایی، مرگ ناگهانی بعد از ۶۰ ثانیه
- **۵ دک ذخیره‌شده** با تعویض یک‌ضربه‌ای؛ **هم‌افزایی دک** (پاداش سبز / جریمه‌ی قرمز) با پیش‌نمایش قدرت
- پس‌زمینه‌ی زنده برای هر جهان (ذرات، عمق، کارت‌های سه‌بعدی) با تنظیم شدت جلوه‌ها

**کارت‌ها و کلکسیون**
- **کارت‌های اتحاد:** ۶۸۰ کارت دوتایی و سه‌تایی با تیراژ محدود جهانی و شماره سریال؛ رهبر کارت قابل انتخاب است
- **اتحاد رسمی:** وقتی دو پروژه‌ی واقعی همکاری کنند، ادمین با `/ally` به کارت‌هایشان درصد قدرت می‌دهد
- ۸ ست کلکسیون با ۳ ستاره (سطح ۱۰ / ۳۰ / ۶۰)، کارت‌های هولو، ۲۱ دستاورد چندمرحله‌ای
- قهرمان ویژه‌ی هفته در صندوق‌ها، قاب‌های ظاهری کارت (با جم یا Stars)

**جامعه و رقابت**
- **جنگ جامعه‌ها:** هر بازیکن طرفدار یکی از ۱۶ جامعه است؛ امتیاز هفتگی، قلمروها، دربی، هدف روزانه، کاپیتان، پیش‌بینی
- **حال‌وهوای بازار:** قیمت واقعی توکن‌ها (CoinGecko) روی قدرت کارت‌ها اثر می‌گذارد
- **باس جهانی هفتگی** با جان مشترک بین همه‌ی بازیکن‌ها
- **آرنا:** دوئل آنلاین ۱ در برابر ۱ با شرط سکه، اتاق دوستانه با کد، رقیب هوش مصنوعی
- **لیگ آرنا:** برنز تا افسانه با امتیاز ELO و فصل‌های ۳۰ روزه
- کلن‌ها با صندوق هفتگی، جدول رتبه‌ها، اسم و آواتار اختصاصی (آواتار = یکی از کارت‌های بازیکن)

**جذب و نگه‌داشت بازیکن**
- عضویت اجباری در کانال بازی موقع شروع، با هدیه‌ی ۵۰۰ سکه و ۲۰ جم
- دعوت پلکانی: جایزه وقتی دوست به جهان ۲ برسد + ۱۰٪ سکه‌های دوستان
- مسیر تازه‌واردها (۷ روز)، جایزه‌ی روزانه، ماموریت‌ها، صندوق استراحت، پاس فصل (رایگان + پریمیوم با Stars)
- ماموریت‌های همکار (اسپانسری) با بررسی عضویت کانال
- یادآوری‌های ربات (صندوق پر، روزانه، نتیجه‌ی جنگ)
- اتصال کیف پول TON و درخواست NFT برای کارت‌های اتحاد شماره‌دار

## امنیت
- داخل تلگرام **سرور** صاحب سکه، جم و کارت‌هاست؛ `src/economy.js` همان قوانین را روی گوشی و سرور اجرا می‌کند.
- هر برد مرحله و هر نبرد باس جهانی را سرور با همان seed و ضربه‌های بازیکن **دوباره شبیه‌سازی** می‌کند.
- نبرد آرنا کامل روی سرور اجرا می‌شود و شرط‌ها تا پایان نبرد نزد سرور می‌ماند؛ اگر سرور ری‌استارت شود، شرط‌ها برگردانده می‌شوند.
- `initData` تلگرام در هر درخواست بررسی می‌شود؛ پرداخت‌ها تکراری‌پذیر نیستند و همان لحظه ذخیره می‌شوند.
- پشتیبان روزانه‌ی خودکار دیتابیس برای ادمین‌ها در تلگرام (و ۷ نسخه‌ی آخر روی دیسک).

## راه‌اندازی روی Render
1. در **@BotFather** ربات بساز و **توکن** را بگیر (ربات فعلی: @GLegends_bot).
2. در **render.com**: New → **Blueprint** → این ریپو (فایل `render.yaml` خودکار خوانده می‌شود). اگر سرویس جدید است، منطقه را Frankfurt انتخاب کن.
3. متغیرها در Environment:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات (الزامی) |
| `ADMIN_IDS` | آیدی عددی تلگرام ادمین‌ها، با کاما |
| `WEBAPP_URL` | آدرس بازی؛ اگر خالی باشد آدرس خود Render استفاده می‌شود |
| `GAME_CHANNEL` | کانال اجباری (پیش‌فرض `@gramlegends_game`، با `off` خاموش می‌شود) |
| `NODE_OPTIONS` | `--max-old-space-size=400` روی Starter، `1536` روی Standard |
| `SAVE_MS` | فاصله‌ی ذخیره‌ی دیتابیس (پیش‌فرض ۳۰۰۰) |
| `MARKET_TOKENS` | توکن‌هایی که قیمتشان روی کارت‌ها اثر دارد |
| `RUNWAYML_API_SECRET` | (اختیاری) ساخت تصویر کارت‌های اتحاد با `/gen` |

4. ربات را در کانال `@gramlegends_game` **ادمین** کن (هیچ دسترسی خاصی لازم نیست) تا عضویت اجباری و ماموریت‌های کانال کار کنند.
5. در BotFather برای ربات یک **Main Mini App** با آدرس بازی بساز تا لینک‌های دعوت و دوئل (`?startapp=...`) بازی را باز کنند. عکس پروفایل (`/setuserpic`) و عکس معرفی (`/setdescriptionpic`) در `docs/bot/` هستند.
6. بعد از Deploy آدرس `/api/status` را باز کن: `webappUrlOk: true`، `channelOk: true`، `setupError: null`.

> ربات را هم‌زمان روی کامپیوتر خودت با همان توکن اجرا نکن (دو نسخه پیام‌ها را بین هم پخش می‌کنند). موقع اوج بازیکن‌ها هم دیپلوی نکن.

**ظرفیت:** پلن Starter برای چند هزار بازیکن اول کافی است؛ حدود ۱۰ هزار بازیکن به Standard و دیسک ۵ گیگ برو؛ بالای ۳۰ هزار بازیکن دیتابیس باید از فایل JSON به یک دیتابیس واقعی منتقل شود.

## دستورهای ادمین در ربات
| دستور | کار |
|---|---|
| `/stats` | آمار بازیکن‌ها، ماندگاری، جایی که بازیکن‌ها گیر می‌کنند |
| `/backup` | ارسال فوری پشتیبان دیتابیس (فقط در چت خصوصی) |
| `/ally <hero> <hero> [درصد] [روز]` · `/ally list` · `/ally remove` | اتحاد رسمی بین دو جامعه |
| `/quest add @channel <جم> <روز> <عنوان>` · `/quest list` · `/quest remove <id>` | ماموریت‌های همکار |
| `/nft list` · `/nft done <n>` · `/nft reject <n>` | درخواست‌های NFT |
| `/art` · `/gen <شماره>` | آپلود یا ساخت تصویر کارت‌های اتحاد (راهنما: `docs/FUSION_ART.md`) |

## نسخه‌ی آفلاین
`python3 tools/build.py` → فایل `dist/ton-legends.html` بدون سرور هم کار می‌کند (بدون امکانات آنلاین). با فعال کردن **GitHub Pages** (Settings → Pages → Source: GitHub Actions) این نسخه خودکار منتشر می‌شود.
